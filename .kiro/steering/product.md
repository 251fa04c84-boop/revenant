# Product: Revenant

Revenant finds abandoned npm dependencies and tells developers how to replace them.

- **Category:** Kiroween 2026, Resurrection (bring dead technology back to life).
- **Audience:** developers maintaining Node or front-end projects with years-old lockfiles.
- **Primary job:** paste a package.json (or a public GitHub repo) and get a ranked list of dead packages, each with a concrete replacement, effort estimate, code diff and a copy-paste migration command.
- **Privacy rule:** the manifest never leaves the browser. Only package names are sent to the public npm registry.

## Voice
Plain, calm and specific. The graveyard theme lives in the visuals and a few headings ("Raise them all"); explanations stay literal and never joke about security.
